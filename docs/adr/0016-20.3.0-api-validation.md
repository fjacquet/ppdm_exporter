# ADR-0016 — 20.3.0 API validation and spec conformance test

Status: Accepted
Date: 2026-11-22

## Context

Dell shipped PPDM 20.3.0. The OpenAPI 3 specs are vendored in `docs/swagger/`:

- `21201-20.3.0.json` — v2 API (379 paths, was 377)
- `21202-20.3.0.json` — v3 API (99 paths, was 85)
- `21200-20.3.0.json` — dpilm v1 — not consumed, unchanged

## Method

1. Spec diff 20.1.0 → 20.3.0 (paths, schemas, properties, property kinds, required, enums).
2. A new test, `internal/ppdm/spec_conformance_test.go`, checks every `json` tag of the
   collector decode structs against the response item schema of the endpoint each decodes
   (`$ref`/`allOf` resolved; `oneOf`/`anyOf` skipped; `integer`≡`number`). Guard test
   `TestConformanceBitesOnRealSpec` proves it is not a vacuous pass.

## Findings

No path, schema or field was removed or renamed, and no property changed JSON kind on a
resource we read. Changes are additive.

| Struct | Endpoint | Verdict |
|---|---|---|
| `activity` | `/api/v2/activities` | ✅ conforms |
| `asset` | `/api/v2/assets` | ✅ conforms |
| `mtree` | `/api/v2/datadomain-mtrees` | ✅ conforms |
| `storageSystem` | `/api/v2/storage-systems` | ✅ conforms |
| `alert` | `/api/v2/alerts` | ✅ conforms |
| `healthResult` | `/api/v3/health-results` | ✅ conforms |

**New enum values** (all pass through to label values; no code switches on them, and
`grafana/`, `deploy/`, `charts/` hard-code none — grepped): `dataMoverType` /
`backupMechanism` `UTS`; `backupStrategy` `BACKUP_CUSTOM`; asset subtypes
`POWERSCALE_UNIFIED`, `POWERSTORE_UNIFIED`, `UNITY_UNIFIED`, `acfs`, `ocfs`, `ocfs2`,
`vxfs`; `ActivitySubcategory` `FLAT_FILE`, `REBOOT`; `Location`/`ReplicaType`
`OBJECT_STORAGE`; `LockMode` `SECURE_LOCK_FOR_SNAPSHOT`.

**New endpoints** (phase-2 candidates, not consumed yet): v3 `rules`, `rules/{id}`,
`rule-execution`, `rule-consistency`, `rule-priority-change`,
`protection-policy-rule-metrics`, `file-selection-rule-metrics`, `copy-management`;
v2 `tls-config`, `nas-utility/validate-nas-appliance`.

**Not covered:** `internal/report` DTOs (`Copy`, jobs, policies) are validated by hand in
ADR-0010 only; `cmd/mockppdm` still serves a `/api/v2/copies` fixture although that
endpoint was removed in 20.1.0 (demo-only, harmless to the exporter).

## Consequences

A future spec bump fails `TestCollectorStructsMatchSpec` when a field is renamed, removed
or retyped: replace the vendored spec file name in `conformanceRows` and fix the one
struct + fixture (ADR-0009).
